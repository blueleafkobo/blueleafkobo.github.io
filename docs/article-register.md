## Maintenance and a possible blog

Leave unknown values explicit rather than estimating them.

For now, retain the existing guides and personal-story pages. A future “Articles” or “From the workshop” index can link to their current URLs without moving them. Product manuals should remain identifiable as reference documentation rather than becoming dated blog posts. If URLs ever change, retain the old URLs through redirects and preserve the original publication dates.

When publishing the new story, add the author's preferred public byline and actual publication date, and update this register. Do not assign today's date as the publication date of older guides. Technical-only updates should not make old articles appear newly written.
